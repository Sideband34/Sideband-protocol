# Code of Conduct

Sideband adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our pledge

We want participation in Sideband to be a harassment-free experience for everyone, regardless of
age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity
and expression, level of experience, education, socio-economic status, nationality, personal
appearance, race, caste, colour, religion, or sexual identity and orientation.

## Expected behaviour

- Be respectful and assume good intent; critique ideas and code, not people.
- Give and accept constructive feedback; credit others' work.
- Be honest about what code does and does not do, especially around funds and security.
- Focus on what is best for users and the project.

## Unacceptable behaviour

- Harassment, insults, sexualised language or imagery, and personal or political attacks.
- Publishing others' private information without explicit permission.
- Spam, including low-effort pull requests or issues opened only to farm rewards.
- Any other conduct that would reasonably be considered inappropriate in a professional setting.

## Scope and enforcement

This code applies in all project spaces (issues, pull requests, discussions, reviews) and when
representing the project elsewhere. Report concerns privately to the maintainers through the
GitHub organization's members or, for sensitive matters, via the private security reporting channel
described in `SECURITY.md`. Maintainers will review every report, keep reporters' identities
confidential, and may warn, temporarily ban, or permanently ban contributors who violate this code,
following the Contributor Covenant enforcement guidelines.
